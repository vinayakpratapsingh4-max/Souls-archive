# SOULS.ARCHIVE

A mobile-first dark fantasy game discovery catalogue.

## Files
- `index.html` — app structure
- `styles.css` — visual design and responsive layout
- `app.js` — game catalogue, search, filters, wishlist and compatibility view
- `manifest.json` — installable web app metadata
- `sw.js` — basic offline caching
- `icon.svg` — app icon

## Run locally
Open `index.html` in a browser. For service worker and PWA features, serve the folder from a local or hosted web server over HTTPS or localhost.

## Publish free
Upload the files to the root of a GitHub repository, then connect that repository to Cloudflare Pages as a static site. No build command is required; the output directory is the repository root.

## Notes
This starter uses illustrative external image URLs and placeholder price information. It does not yet fetch live store prices, user reviews, or hardware benchmarks. Verify platform availability with official stores before purchasing.
